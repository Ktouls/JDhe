字根图 V9 注释与提示

  1. 键位 H 的笔画“点”类包括了笔画“捺（乀）”（如“哀”的末形）。
  2. 键位 D 的笔画“横”类包括了笔画“提（㇀）”（如“刁”的末形）。
  3. 键位 P 的笔画“竖”类包括了笔画“竖钩”（如“手”的末形）。
  4. 键位 R 的笔画“折”类包括了各种折撇、折钩、横折钩、竖折钩、折折钩等（如“乃”的首形）。
  5. 键位 N 的字根“囗”是框（如“圆”和“黑”的首形），而键位 O 的“口”是 kǒu（如“员”、“史”和“哟”的首形）。
  6. 键位 H 的字根“釆”并非采集的采字，而是“番”字的上部。
  7. 键位 Z 的字根“艹”是草字头（如“花”的首形），并非“廾”，类似“弄”的末形取“竖”。
简单鹤核心拆分口诀
笔顺优先（无笔画粘连的口可无视笔顺），首末取大，相交也拆，插隔也取，字根字重复，禾取丿八。
规则 01

笔顺优先

严格按规范笔顺取首字根和末字根。特例：无笔画粘连的「口」可无视笔顺。

规则 02

首末取大

取首末字根时，优先取覆盖笔画更多的大字根，让拆分保持直观、不碎裂。

规则 03

相交也拆

笔画相交也拆开取根。官方例字：由 = 日(v) + 丨(p)。

规则 04

插隔也取

笔画被穿插隔开依然取根。官方例字：平 = 一(d) + 十(s)。

规则 05

字根字重复

单字本身即是字根时重复该键。官方例字：虫 = 虫(f) + 虫(f)。

规则 06

禾取丿八

「禾」按 丿(u) 与 八(f) 处理，记住这一条即可通吃禾字旁汉字。

贴心容错机制

你以为的拆法也许正是大家以为的。简单鹤内置大量贴心容错，当一个字有两种打法都能打出时，不用怀疑是不是打错了。

固词 vs 动词模式

固词（默认）：前 4 码固定走简单鹤码表，四码单字与词序确定性极强。
动词：仅前 3 码固定，4 码随使用动态调频（Ctrl + ~ 随时切换）。

原则：除 qo / xo 两个飞键建议记住外，其余所有简词均保留完整全码且不出简让全，忘了就打全码，随用随熟即可。

易混淆的 4 组键位

1. in 在 B，ing 在 K：「拼」=pb，「平」=pk。
2. V 的双重角色：首键 zh，次键 ui / ü（如「追」=vv）。
3. L 与 N 长韵母：L = iang/uang（「亮」=ll），N = iao（「料」=ln）。
4. ü 系列常写作 u：「学(xue)」=xt，「云(yun)」=yy。

97 字根练习须知

通过高频重复建立指尖条件反射，告别拿着字根表死背
  1. 屏幕给出简单鹤字根，按下对应的 字母键（物理键盘或触屏键帽均可）。
  2. 按对自动跳下一题，连击越高积分倍率越高（最高 ×4）。
  3. 按错会很快重复出现（间隔重复算法），专治记不住的字根。
  4. 想不起来就 按空格看答案提示——不跳过、不断连击，看清后自己敲对才继续。
  5. 推荐默认 「循序渐进」模式：从 3 键起步，全掌握后自动解锁下一键。
