核心拆分口诀
笔顺优先（无笔画粘连的口可无视笔顺），首末取大，相交也拆，插隔也取，字根字重复，禾取丿八。
规则 01

笔顺优先

按规范笔顺取首字根和末字根。无笔画粘连的口可无视笔顺。

规则 02

首末取大

优先取覆盖笔画更多的大字根，让拆字保持整体直觉、不碎裂。

规则 03

相交也拆

笔画相交也拆开取根。例字：由 = 日(v) + 丨(p)。

规则 04

插隔也取

笔画被穿插隔开依然取根。例字：平 = 一(d) + 十(s)。

规则 05

字根字重复

单字本身即是字根时重复该键。例字：虫 = 虫(f) + 虫(f)。

规则 06

禾取丿八

「禾」按 丿(u) 与 八(f) 处理，记住一条即可通吃禾字旁。

原则：除 qo / xo 两个飞键建议记住外，其余简词均保留完整全码且不出简让全，忘了就打全码，随用随熟。

细微辨析与补充

把容易混淆的几处，一次说清。

字根细微辨析（7 条）

  1. H「点」含捺（乀，如「哀」末形）；D「横」含提（㇀，如「刁」末形）。
  2. P「竖」含竖钩（如「手」末形）；R「折」含各类折撇/折钩（如「乃」首形）。
  3. N「囗」是框（圆、黑首形），O「口」是 kǒu（员、史首形）。
  4. H「釆」指「番」的上部，并非「采」；Z「艹」指草字头，并非「廾」。

容错机制 · 固词/动词 · 双拼易混

贴心容错：内置大量直觉拆法容错，记不清细枝末节也能直接上屏。
固词 vs 动词：默认「固词」前 4 码固定顺序；按 Ctrl + ~ 可切动词动态调频。
双拼易混 4 组：in=B / ing=K；V=zh 或 ui/ü；L=iang/uang、N=iao；ü 常作 u。

测评方法

数据怎么来的，完全透明。

全码与出简，为什么重码差这么多

全码是「双拼两码 + 首末形码两码」，形码把同音字彻底分开，所以前 1500 字只有 18 个重码字。 出简允许两码或三码直接出字，省了击键，但同音字挤在更短的码位上，重码自然变多——这是所有音形方案的共同规律，不是缺陷。

重码主要来自同音

音形方案的前两码是拼音，同音字天然共用入口。简单鹤用乱序字根压低形码重码， 剩下的重码基本集中在高频同音字上，属于「一眼就能看出该选哪个」的类型。

码长怎么算

码长为字均用键数，不含空格确认键。全码恒为 4.00；出简后平均 1.75，即大部分常用字两键左右就能出字。 若把空格算作一键，实际击键为码长 +1。

测评口径

字频取官方码表 jde.dict.yaml 的权重，按字频从高到低取前 N 字；每字只与「同码单字」比较，不含词组。 全部数据由 python3 scripts/assess.py 生成，结果固定可复现，不是抽样估算。

本页只测单字（不含词组与整句）；词组性能另见「性能实测」区的多方案对照。数据由脚本从本仓库码表直接计算，复算命令 python3 scripts/assess.py。

  1. 屏幕给出简单鹤字根，按下对应的 字母键（物理键盘或触屏键帽均可）。
  2. 按对自动跳下一题，连击越高积分倍率越高（最高 ×4）。
  3. 按错会很快重复出现（间隔重复算法），专治记不住的字根。
  4. 新字根第一次出现会直接显示答案，看清后照着敲对即可，不用干等。
  5. 再遇到时想不起来就 按空格看答案提示——不跳过、不断连击，看清后自己敲对才继续。
  6. 推荐默认 「循序渐进」模式：从 3 键起步，全掌握后自动解锁下一键。
